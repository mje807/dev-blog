# POST_TEMPLATE

아래 템플릿을 복사해서 적절한 `content/<category>/...md` 경로에 저장하면 됩니다.

```md
---
title: 글 제목
date: 2026-03-23
tags:
  - tag-1
  - tag-2
excerpt: 이 글이 어떤 문제를 풀고, 어떤 독자에게 어떤 가치를 주는지 1~2문장으로 요약합니다.
draft: true
featured: false
series:
---

# 글 제목

이 글이 푸는 문제를 첫 문단에서 분명히 적습니다.

독자가 왜 이 글을 읽어야 하는지, 어떤 상황에서 도움이 되는지 빠르게 설명합니다.

## 배경

문제의 맥락과 현재 한계를 정리합니다.

## 핵심 개념

핵심 개념, 구조, 원리를 설명합니다.

## 실제 운영 관점

실전에서 부딪히는 트레이드오프, 비용, 실패 포인트를 적습니다.

## 예시

```ts
export function example() {
  return 'replace me';
}
```

## 작성 팁
- 첫 두 문단이 카드 `excerpt`와 연결된다고 생각하고 씁니다.
- `draft: true`로 시작하고, 공개 직전에 `false`로 바꿉니다.
- 시리즈가 아니면 `series:`는 비워둬도 됩니다.
- `featured: true`는 메인 랜딩에 먼저 보여주고 싶은 글에만 사용합니다.
